Design mockup for the shipped /hivelog dashboard — it shows the layout, the priority model (severity stripe + status chip, summary before detail) and the widget set. Apiaries, hives, tasks, stock levels and figures are illustrative, not live data. Queen-marking colour (2024 → green), ISO week numbering, the CBR line and the seasonal-calendar week ranges follow the module’s real conventions. The apiary list is now at /hivelog/apiaries, reached from the Apiaries tile (with a single apiary the tile links straight to it); the Net YTD tile links to that apiary’s financial report, or, with more than one, the combined all-apiaries report at /hivelog/apiaries/financial-report. The closing per-apiary summary table shown in earlier drafts was dropped as redundant with the Apiaries tile (task 0058).

The Fraunces / IBM Plex type and beeswax / pine-green palette are this mockup’s own visual proposal. The shipped module is theme-neutral — it inherits the active admin theme’s typography and keeps to its own hex palette — so the live page carries this structure, not this styling.
