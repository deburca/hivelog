# Release 3.0.1

Patch release for 3.0.0. No schema change and no update hook.

## Fixes
- **Reports and the dashboard keep a moved hive's history with the apiary it was written under** (task 0231).
  After a hive moved, the cost and yield report and the dashboard's "inspections this month" counted its
  records through the hive's current apiary, so the old apiary lost them and the new one gained them. They now
  count by the apiary each record carries.

## Documentation
- Tasks 0225, 0226 and 0227 (entitlement interface, hive limit, commerce package) revised for 3.0.0 and the
  commerce decisions.
