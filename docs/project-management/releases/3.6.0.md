# Release 3.6.0

Minor release: the finance pages link to one another, and the stat tiles use the width of a phone held sideways. No schema
change, no update hook.

## Changes
- **Finance cross-links.** Inventory Items links to the financial report like Purchases and Products do; the combined and
  per-apiary reports link back to Inventory Items, Purchases and Products (the per-apiary one also to the all-apiaries
  report), each only where the viewer may open it.
- **Stat tiles on a landscape phone.** Two to a row from 481 to 768px, one to a row at 480px and below (it was one at every
  width up to 768px).
