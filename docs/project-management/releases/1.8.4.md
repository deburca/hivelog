# Release 1.8.4

## Highlights
- **CBR summary banner tokenised.** `.hivelog-cbr-summary` in
  `css/hivelog.buttons.css` was the one selector task 0062 left with
  hard-coded hex — `buttons.css` was out of that pass's scope. Its
  border and background now read `var(--hivelog-border)` /
  `var(--hivelog-surface-2)` from the `:root` token surface added in
  1.8.3. `css/hivelog.buttons.css` is in the `hivelog/buttons` library,
  which already depends on `hivelog/responsive`, so the tokens are in
  scope with no library change. Both tokens carry the exact stock values
  they replace, so a stock-theme render is byte-for-byte unchanged. This
  clears the last carry-forward from task 0062 — the beeswax skin can now
  drop its `.hivelog-cbr-summary` restatement.

## Target tasks
- [[0070-tokenise-cbr-summary]] — module side shipped here (PR #137). The
  beeswax cleanup (drop its `.hivelog-cbr-summary` colour block, now
  covered by its `body.hivelog-page` token bridge) is gated on cms2
  pinning hivelog to 1.8.4.

## Upgrade notes
