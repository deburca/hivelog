# Release 1.8.0

## Highlights
- **Dashboard landing page.** `/hivelog` is now an operational dashboard
  instead of a bare apiary table: a "Needs attention" priority queue
  (overdue / due seasonal actions + low stock), six stat tiles, an
  "Upcoming" look-ahead and a cross-entity "Recent activity" feed. Custom
  `DashboardController`, new `hivelog:stat-tile` SDC, `hivelog/dashboard`
  CSS library. First-run welcome card and an "all caught up" empty state.
- **Information architecture change (ADR-0057).** The apiary collection
  moves from `/hivelog` to `/hivelog/apiaries` (no redirect — `/hivelog`
  stays valid, it just renders the dashboard). The HiveLog menu tree is
  repointed at the dashboard and the breadcrumb root now targets it
  (amends ADR-0013). The CBR summary moves from the apiary list builder
  to the dashboard header.
- **Combined financial report.** A new `/hivelog/apiaries/financial-report`
  sums the per-apiary cost/income aggregation across every viewable
  apiary (summary + "All apiaries" total + 5-year trend). It is the
  dashboard "Net YTD" tile's target when the user has more than one
  apiary; with exactly one, that tile links straight to the apiary's own
  report.
- **List / report polish.** Page titles drop the redundant "HiveLog - "
  prefix; every list / report page ends its breadcrumb with its own name;
  financial-report figures are right-aligned with tabular numerals and a
  consistent total-row typeface; the "Add …" / year-selector action bar
  floats right with spacing, matching the dashboard header.
- **Theme identity (ADR-0060).** The mockup's Fraunces / IBM Plex +
  beeswax / pine look is delivered by a site theme (`beeswax`), not the
  module — the module stays theme-neutral. No module change beyond the
  existing `--hivelog-btn-*` token surface.

## Upgrade notes
- Anyone with a bookmark or deep link to the apiary list at `/hivelog`
  now lands on the dashboard and clicks through to **Apiaries**
  (`/hivelog/apiaries`). No redirect is provided (ADR-0057) — `/hivelog`
  was never a dedicated list URL.
