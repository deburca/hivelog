# Release 3.3.0

Minor release: collection filters fold away on a phone. No schema change, no update hook.

## Changes
- **Filters collapse on a phone.** Every collection's filter form (hives, inspections, queens, observations, calendar,
  action logs, inventory, products, apiaries) sat above its table as a column of four or five fields, so on a phone the
  table started below the fold. Each is now wrapped in a panel whose "Filters" bar opens and closes it, closed up to 768px,
  with a badge ("1 active") saying how many filters are set. From 769px up nothing changes. It is CSS only (a hidden
  checkbox and its label, like the app nav's Menu button), so there is no script and no flash of an open panel.
- `HivelogFilterPanel::wrap()` does it for any form carrying the `hivelog-filter-form` class, from `hivelog_form_alter()`;
  a new filter form needs nothing beyond that class.

## Upgrade notes
Run `drush cr`. The panel's classes (`.hivelog-filter-panel`, `__toggle`, `__label`, `__count`) are new theming surface.
Pair with beeswax 1.2.1, which also keeps the breadcrumb on one line on a phone (the module works without it).
