# Release 2.2.2

## Highlights
- **Fix: nav submenu reachable on touch devices wider than 768px (task 0165).**
  The two-tier nav strip's always-open submenu layout only applied at
  `max-width: 768px`. On a touch device above that width (an iPad in
  portrait or landscape) there is no hover, and tapping a hub link navigates
  straight to the hub's destination, so Hives, Inspections, Queens, Inventory
  and the other Apiaries children were reachable only through cross-links on
  other pages. The layout now also applies under `@media (hover: none)`,
  sharing one block with the width rule. `hover` describes the primary input,
  so a touch laptop with a mouse keeps the dropdown. A touch tablet gets the
  full mobile layout (primary items stacked, children indented) — worth a
  look on a real iPad.
- **Docs: AGENTS.md refreshed for the hive component work (task 0167).**
  Adds `HiveComponent`, its guards and dedicated selection plugin,
  `Hive::getEmptyWeightKg()`, `InventoryItem.weight_kg`, the net-weight stat
  tile and the `0106-N` delete-registry rows; corrects the entity counts and
  makes the phpstan baseline figure counts-free. The task template gains an
  "AGENTS.md updated" acceptance criterion.
- **Housekeeping.** The stale "Setup" wording in the nav CSS header now says
  "Insights" (task 0173, folded into 0165).
