# Release 3.2.0

Minor release: friendly page-not-found and access-denied pages. No schema change, no update hook.

## Changes
- **Page not found** (`/hivelog/page-not-found`): a confused bee beside an empty hive with a "Vacant" sign, "Oops! This
  hive is empty.", and a link to the front page.
- **Access denied** (`/hivelog/access-denied`): two bees flanking a "Residents only" sign, "Hold on, this hive isn't
  yours.", and, for a signed-out visitor only, a Sign in link that returns to the refused page.
- Both are the new `hivelog:error-page` component, open to everyone (a refused visitor must be able to read the page that
  says so), with the scene as an inline SVG hidden from screen readers and the headline as the page's H1. The scene's
  colours are `--hivelog-error-*` custom properties with a fallback palette; they do not follow dark mode.

## Upgrade notes
Run `drush cr`. **The module changes no setting**: a site uses the pages by setting `system.site:page.404` to
`/hivelog/page-not-found` and `system.site:page.403` to `/hivelog/access-denied`
(`drush cset system.site page.404 /hivelog/page-not-found`). Until then the theme's own error pages show.
