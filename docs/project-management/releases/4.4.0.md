# Release 4.4.0

Minor release. Includes the harvest consolidation series and calendar-action week display improvements. New update hooks migrate existing data for the new per-harvest apiary/hive/date stamping (`hivelog_update_10039` through `10040`).

## Changes
- **Calendar action weeks now show dates (task 0283).** The window column on the collection list and the fact tiles on individual pages display date ranges followed by week numbers, e.g. "30 Mar – 5 Apr (W14–W18)". A single-week action shows the date range only ("30 Mar"). `HivelogWeekDates` is the new helper class powering this across all views.
- **Every harvest carries its own apiary, hive and date (task 0285).** HarvestYield rows now store their `apiary`, `hive` (when from one hive) and `harvest_date` directly as fields, set on creation and never changed. Existing log-reported harvests were migrated via `hivelog_update_10040`. Directly recorded harvests always had these fields. This lets cost and yield reports count harvests by the apiary they belong to regardless of where the source hive now lives.
- **One list of harvests, totals that count them all (task 0286).** The "Harvests" section on both the hive and apiary canonical pages lists every harvest — calendar-reported or directly recorded — in one combined table with a Source column linking to the log (or "Recorded directly"), a per-product breakdown across years, and totals. Previously the two sources were split into separate tables.
- **Harvest totals are per product, never summed across units (task 0284).** The "Harvest this year" tile on each hive shows the total of its main product only, names it in the sub-line and says "+N other products". No cross-product summation is attempted because units are free text.
- **A calendar harvest uses `HarvestYield` fields (task 0287).** When a logged action is reported done, its yield now populates the new `HarvestYield` row's `apiary`, `hive`, and `harvest_date` fields alongside quantity. It also creates the product if it doesn't already exist in the apiary's catalogue (for unplanned products).
- **Wording: "Expected harvest" vs "Harvest" (task 0288).** The plan entity (`CalendarActionProductYield`) is now labelled "Expected harvest"; the fact entity (`HarvestYield`) is "Harvest". Both names are consistent across add forms, sections, column headers and links.

## Upgrade notes
