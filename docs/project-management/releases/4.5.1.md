# Release 4.5.1

Two layout fixes to the 4.5.0 inspection features, found on the live hive page. No update hooks, no API change, no new
permissions. Covers every change on `main` since the 4.5.0 tag.

## Changes
- **Inspection buttons together (hive page).** Add Inspection floated to the middle of the Inspections heading while
  Quick Inspection sat on the right. Both buttons are now in one action container on the right, like the other
  multi-button headings. A regression test keeps the heading to a title and one action group.
- **Quick inspection in vertical tabs.** `?mode=quick` was one long page. It now groups its fields in vertical tabs like
  the full form: Overview, Queen status, Stores and colony, Notes, then the Queen observation and Next visit tabs when
  they apply. The full form is unchanged.
- **Docs.** AGENTS.md notes that a theme which recolours a form item's label on `:focus-within` must leave the vertical
  tabs wrapper out (beeswax turned the "Inspection sections" label accent-coloured while focus was inside the tabs; the
  fix is in the theme, released separately).

## Upgrade notes
- Run `drush cr`. No `drush updb` is needed (no update hooks).
- A theme that styles `.form-item:focus-within > label` should exclude `.form-type-vertical-tabs`, or the tabs' label
  changes colour when a tab or field inside has focus.

## Known limitations
- As in 4.5.0: the frame fields are not in `collective`'s context payload.
