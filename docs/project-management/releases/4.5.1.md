# Release 4.5.1

Two layout fixes to the 4.5.0 inspection features, consistent field labels (task 0297) and a sign-out fix for newer
simple_oauth. No update hooks, no change to the API's shape, field keys or `api_version`, no new permissions. Covers every
change on `main` since the 4.5.0 tag.

## Changes
- **Inspection buttons together (hive page).** Add Inspection floated to the middle of the Inspections heading while
  Quick Inspection sat on the right. Both buttons are now in one action container on the right, like the other
  multi-button headings. A regression test keeps the heading to a title and one action group.
- **Quick inspection in vertical tabs.** `?mode=quick` was one long page. It now groups its fields in vertical tabs like
  the full form: Overview, Queen status, Stores and colony, Notes, then the Queen observation and Next visit tabs when
  they apply. The full form is unchanged.
- **Consistent field labels (task 0297, ADR-0112).** Labels on hives, inspections, queens, queen observations, calendar
  actions and both action logs are in sentence case ("Hive name", "Inspection date", "Queen seen"). The observation's
  `active` is "Laying or moving on the comb", so "Active" means in service only. `images` fields are "Photos"; the
  inspection's weight is "Weight (kg)". `queen.name` is the queen's name: label "Name", example "Maud". List headers and
  filters naming these fields use the same words, and the Danish translation follows. `/api/v1/schema` serves the new
  labels under the same keys.
- **Sign-out on simple_oauth 6.1.5.** `POST /api/v1/sign-out` reads the token's client from its own `client` field instead
  of `getConsumer()`, deprecated in simple_oauth 6.1.5 (its replacement is not in 6.1.4). Same behaviour on every 6.1.x.
- **Docs.** AGENTS.md notes that a theme which recolours a form item's label on `:focus-within` must leave the vertical
  tabs wrapper out (beeswax turned the "Inspection sections" label accent-coloured while focus was inside the tabs; the
  fix is in the theme, released separately).

## Upgrade notes
- Run `drush cr`. No `drush updb` is needed (no update hooks).
- A theme that styles `.form-item:focus-within > label` should exclude `.form-type-vertical-tabs`, or the tabs' label
  changes colour when a tab or field inside has focus.
- **Field app.** Only labels changed. A client that matches on field keys, as Vinculum does, needs no change; re-capture
  any schema fixture that quotes labels. A site that overrode a label string in its own translation (for example
  "Queen ID" or "Pictures") needs to translate the new string.

## Known limitations
- As in 4.5.0: the frame fields are not in `collective`'s context payload.
