# Release 3.1.1

Patch release for 3.1.0: three phone-layout fixes found on a phone against hivelog.eu. No schema change, no update hook.

## Changes
- **Stacked cards.** On a phone a list table becomes labelled cards, and each text node and element in a cell had become a
  separate flex item, so "Unreported (Overdue)" was spread across the row. A filled cell's content now sits in one
  `.hivelog-entity-table__cell` span.
- **Empty rows.** A cell with nothing in it (Week Completed, Notes, …) is marked `.hivelog-entity-table__empty` and left out
  of the card, instead of showing a label with nothing beside it. On a wide screen the cell stays.
- **Date filters.** iOS Safari gave a date field an intrinsic width wider than the filter panel, pushing it past the panel's
  right edge; on phones the fields now have `min-width: 0`, a 100% maximum and no native appearance.

## Upgrade notes
Run `drush cr`. Pair with beeswax 1.2.0: it also left-aligns the section headings on phones (the module works without it)
and adds the "Match the device" colour scheme.
