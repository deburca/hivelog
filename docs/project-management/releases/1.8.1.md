# Release 1.8.1

## Highlights
- **Breadcrumbs on every HiveLog page.** `/hivelog/product/1`,
  `/hivelog/inventory-item/…`, `/hivelog/inventory-purchase/…`, the
  calendar-action requirement / yield edit pages and the Layout Builder
  override routes had a stub trail (`Home › <label>`). The breadcrumb
  builder now matches by path (every route under `/hivelog`) and threads
  the full ancestor chain for those entity types, so all pages read
  `Home › HiveLog › <Apiary> [› …] › <Name>`. Orphan-safe.
- **Consistent row actions.** The `/hivelog/hives`, `/hivelog/inspections`,
  `/hivelog/calendar-actions`, `/hivelog/hive-action-logs`,
  `/hivelog/apiary-action-logs` and `/hivelog/queen-observations`
  collections rendered their Operations column as Drupal's collapsed
  dropbutton; they now use the same flat `hivelog:button-group`
  (Edit + Delete) as every other list, the embedded child lists and the
  dashboard. New shared `HivelogListBuilder` base.
