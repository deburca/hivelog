# Release 3.4.0

Minor release: a hive autocomplete names the apiary, the dashboard's "Needs attention" folds after five rows, and the 403
scene is centred. No schema change, no update hook.

## Changes
- **A hive field shows the apiary.** Dropdown rows and the field's text read "VV-01 · Vand Værk (1)" instead of "VV-01 (1)",
  since hive names repeat across apiaries. Every hive autocomplete gets it, a submodule's included. The "(id)" stays: it is how
  the text is resolved to a hive.
- **"Needs attention" folds after five rows.** The rest are behind "Show N more" (a native `<details>`); the header count still
  gives the total, and overdue rows come first. The mobile API still returns every row.
- **The 403 scene is centred** in its card. For dark mode, a theme sets the `--hivelog-error-*` properties (beeswax 1.2.2 does).

## Upgrade notes
Run `drush cr`. New classes: `.hivelog-attention__more`, `__more-summary`, `__more-show`, `__more-hide`. Pair with beeswax
1.2.2 for the dark error scenes (the module works without it).
