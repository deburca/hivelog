# Release 2.7.0

## Highlights
- **New optional submodule `hivelog_api` (task 0201): a per-user, OAuth-secured
  JSON:API for field apps.** It serves the field-workflow records (apiaries,
  hives, inspections, queens, queen observations, calendar actions, both action
  logs and file uploads) under a versioned path, `/hivelog/api/v1`. Everything
  else (inventory, products, components, sensors, API clients, AI providers,
  users) is not reachable there. It is the backend for the planned iOS app
  (ADR-0107) and for any future client.
  - **Sign-in is OAuth2 authorization code with PKCE** through a public client
    (no secret) that the module creates on install, with a `hivelog_field_app`
    role and scope. Give the role to the beekeepers who may use the app; it also
    caps what their token can do (no delete, no inventory).
  - **It changes no site-wide setting.** Writes work on the versioned path even
    when the site has JSON:API in read-only mode; plain `/jsonapi` keeps whatever
    the site chose. A token with the app's scope is refused on `/jsonapi` outside
    the prefix, which also stops it listing other users.
  - **Writes use the shared validation of 2.6.0**: a rule broken through the API
    is a 422 naming the field, and a record cannot be created under, or moved
    into, someone else's apiary or hive. Clients may supply their own UUIDs, and
    a retried create is a clean 409.
  - **A pinned contract** (every exposed resource and field name) fails CI if a
    field is renamed or removed, so a shipped app is not silently broken.
  - A public `GET /hivelog/api/v1` tells a client the API version and OAuth
    endpoints before it signs in.
- **Planning notes (no code):** the JSON:API spike (0198) and the offline decision
  (0199) are recorded, with ADR-0107 accepted.

## Upgrade notes
- **Nothing changes unless you enable `hivelog_api`.** It is optional and HiveLog
  core does not depend on it.
- To use it: `composer require drupal/simple_oauth` (6.1 or later), then
  `drush en hivelog_api -y`, then generate Simple OAuth's key pair
  (Configuration > People > Simple OAuth, kept outside the web root). The status
  report errors until the keys exist and warns if any other OAuth scope enables
  the authorization-code grant, which a public client could then request.
- Run `drush cr` after upgrading.
- Known limit: the app role holds `edit own apiary`, `hive` and `queen`, because
  adding a child record needs update rights on its parent. The app token can
  therefore also edit those records.
