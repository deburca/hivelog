# Release 1.8.7

## Highlights
- **Calendar Actions week-range filter + "Open seasonal tasks" footnote
  (task 0073).** `/hivelog/calendar-actions` previously showed every
  calendar action across every apiary with no filter and no indication of
  which rows were pending, and the dashboard's "Open seasonal tasks" stat
  tile linked there with no filtering at all. The page now has a From
  week / To week filter plus an Apiary column, the stat tile links with
  the filter pre-filled to "this week through week 53", and a footnote
  explains exactly how the tile's count is calculated.

## Target tasks
- [[0073-calendar-actions-week-filter]]

## Schema / update hooks
- None.

## Upgrade notes
- No API or schema change. `entity.calendar_action.collection` now routes
  through `CalendarActionController::collection()` instead of Drupal's
  default entity list — `CalendarActionListBuilder` itself is unchanged
  and still the entity type's registered list builder.
