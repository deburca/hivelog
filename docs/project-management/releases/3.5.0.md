# Release 3.5.0

Minor release: the in-page nav strip loses its "Dashboard" item. No schema change, no update hook.

## Changes
- **No Dashboard item in the strip.** The header menu's "HiveLog" item already goes to the dashboard, so the strip starts at
  Apiaries (then Insights, where a submodule gives it children). The dashboard stays reachable from that header item and the
  breadcrumb's "HiveLog" crumb. On the dashboard itself no strip item is marked active.
- `HivelogAppNavBuilder::dashboardItem()` and the `dashboard` entry of `GROUP_ORDER` are gone; a site or theme that styled
  the strip's first item as the dashboard needs nothing changed, it simply is not there.

## Upgrade notes
Run `drush cr`.
