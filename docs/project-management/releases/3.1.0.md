# Release 3.1.0

Minor release for 3.0.2: a UI polish pass for the beeswax theme (1.1.0). No schema change, no update hook.

## Changes
- **Buttons, not links.** "Add a member", "Move to another apiary" and "Manage members" render as buttons; Delete
  forms use the danger variant with a Cancel button and room between them.
- **Dashboard.** The page title is "Dashboard" (the header already carries the brand).
- **Detail tables.** One label column width per page, muted labels, and no visible "Field / Value" header (it stays
  for screen readers); more space between sections and under the Edit / Delete cluster.
- **Date fields.** The label and description match every other field's.
- **Tables.** A date and the Edit / Delete cluster stay on one line; every table's "Operations" header is visually
  hidden, and list tables get a header cell over their buttons so the strip spans the table.
- **Queens.** The colour reads "Blue", not "Blue (years ending 0, 5)", on the hive, queen and list pages; the hives
  table shows "2025 · Blue · Buckfast".
- **Anonymous.** A record by the anonymous user names it in plain text instead of linking to `/user/0`.
- **Navigation.** The strip's "you are in this section" state is a tint; the hexagon's clip-path had cut the old
  outline to a line above and below the label.
- **Filter fields.** The select and text filters are one height and their labels line up (beeswax 1.1.1).

## Upgrade notes
Run `drush cr`. The removed `.hivelog-masthead__mark` / `__word` classes are no longer emitted; a custom theme that
styled them has nothing to style. Pair with beeswax 1.1.1 for the matching theme changes (the module works without).
