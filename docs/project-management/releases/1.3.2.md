# Release 1.3.2

## Highlights
- Button group variant colours corrected: View and Edit buttons now render grey
  (default); only Delete renders red (danger).

## Included work
- **PR #88** — fix(theme): correct button-group variant colours.
  - Two compounding causes resolved:
    1. `button.twig` emitted theme framework classes (`btn`, `btn-primary`,
       `btn-danger`, `btn-default`, `join-item`) giving the active admin theme
       authority to colour buttons. `btn-danger` on Delete caused the theme to
       paint the entire group red.
    2. `.hivelog-button-group` was not a registered context wrapper in
       `hivelog.buttons.css`, so the module's own `--hivelog-btn-*` token rules
       never applied to grouped buttons.
  - All theme framework classes removed from `button.twig`; semantic modifiers
    are now `button--primary`, `button--danger`, `button--default` only.
  - `.hivelog-button-group` added as the eighth context wrapper in all `:is()`
    rule blocks in `hivelog.buttons.css`.
  - Fixes #87.
