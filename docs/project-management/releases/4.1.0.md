# Release 4.1.0

Minor release: the field-app API tells the Vinculum app two things it had to guess. Additive: `api_version` stays 1.
No schema change, no update hook.

## Changes
- **New: `page_prefix` in the discovery document** (`GET /api/v1`, under `meta.hivelog_api`): where the site serves
  its pages, `hivelog` or the site's `$settings['hivelog_path_prefix']`. A QR label reads
  `/<page_prefix>/hive/<id>/quick`.
- **New: `GET /api/v1/computed/apiary-roles`** (signed in): the user's role in each apiary they can see, as
  `{apiary: {id, name}, role}` with `role` `owner`, `keeper` or `novice` (null for access by a site permission
  without membership), and `meta.count`. A client uses it to show only what the user may do; every write is still
  decided by the server.

## Upgrade notes
- Run `drush cr` so the new route is found. Nothing else.
