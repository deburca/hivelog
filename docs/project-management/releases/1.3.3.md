# Release 1.3.3

## Highlights
- Button group spacing corrected: adjacent grouped buttons no longer have
  unwanted gaps between them.

## Included work
- **PR #90** — fix(theme): remove margin-right bleed into button groups.
  - `margin-right: 0.5em` was applied to all `.button` elements across every
    context wrapper including `.hivelog-button-group`, creating gaps that fought
    the `margin-left: -1px` border-collapse rule.
  - Scoped `margin-right: 0.5em` to a separate rule covering the seven
    standalone contexts only; `.hivelog-button-group` explicitly excluded.
  - Removed now-redundant `margin-right: 0` override from the compact
    button-group block.
  - Fixes #89.
