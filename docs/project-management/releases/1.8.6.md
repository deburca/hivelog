# Release 1.8.6

## Highlights
- **"Upcoming" panel no longer shows completed hive-scoped tasks (task
  0072).** A hive-scoped calendar action stayed on the dashboard's
  "Upcoming" list even after every hive in its apiary had reported it
  done/ignored for the year — `buildUpcoming()` only checked reported
  status for apiary-scoped actions. Added `reportedHiveActionIds()` to
  close the same gap for hive-scoped actions, so "Upcoming" only shows
  tasks that are actually still outstanding.

## Target tasks
- [[0072-upcoming-panel-hive-scope-completion]]

## Schema / update hooks
- None.

## Upgrade notes
- No API or schema change. Behaviour change is limited to the "Upcoming"
  panel now hiding a hive-scoped row once every hive has reported it for
  the year, matching the existing apiary-scoped behaviour.
