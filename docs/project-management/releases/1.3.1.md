# Release 1.3.1

## Highlights
- Button group segmented control: inner corners are now squared off and the
  shared border collapses to a single 1px line.

## Included work
- **PR #86** — fix(theme): joined corners and border collapse for button groups.
  - Removed dead Tailwind arbitrary-variant classes from `button-group.twig`
    (`[&>:not(:first-child)]:rounded-l-none` etc.) — never compiled; no effect.
  - Wrapper simplified to `<div class="hivelog-button-group">`.
  - Plain CSS added to `hivelog.buttons.css`: `inline-flex` container; `.button
    + .button` uses `margin-left: -1px` to collapse the shared border;
    `:not(:last-child)` squares right-hand corners; `:not(:first-child)` squares
    left-hand corners.
  - Fixes #85.
