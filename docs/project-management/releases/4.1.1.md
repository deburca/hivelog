# Release 4.1.1

Patch release. No schema change, no update hook.

## Changes
- **Fix: the API's 401 no longer catches other modules' routes under `/api/v1`.** Since 4.0.0 every anonymous request
  under the prefix got `"Sign in to use the HiveLog API."`, including FriendlyCaptcha's own puzzle route
  (`/api/v1/puzzle`), which broke the login form of a site using its local endpoint. Only `hivelog_api.*` and
  `jsonapi.*` routes are challenged now.
