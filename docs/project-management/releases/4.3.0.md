# Release 4.3.0

Minor release. No schema change, no update hook, no new route or permission. Includes the apiary page tweaks that were
prepared as 4.2.3 and never tagged (Manage members beside Edit, tile labels at the bottom, the viewer's apiary role).

## Changes
- **Detail pages show their facts as stat tiles (tasks 0256 to 0262).** One shared strip helper turns a record's short
  facts (status, type, dates, yes/no) into a row of tiles, replacing label/value tables on the hive, queen, queen
  observation, inspection, inventory item, inventory purchase, product, calendar action, and hive and apiary action log
  pages. The inspection page groups its tiles under its existing sections and tints the plainly good or bad ones (low
  honey stores, weak population, serious disease). The cost and yield reports open with a totals strip (Consumable cost,
  Active depreciation, Total cost, Potential income, Net). A new `ok` tint (`--hivelog-ok`, `--hivelog-ok-tint`) joins
  the critical and warning ones; a theme may redefine it.
- **The hive page opens with core fact tiles (task 0257):** Status, Type · Material, Temperament, Queen (or "No queen"
  with an add link) and Empty weight. They are web-only; the field app's computed stat-tiles endpoint is unchanged.
- **The apiary page shows the dashboard's figures for that apiary (task 0263):** Active hives, Open seasonal tasks
  (critical when overdue), Inspections this month (counted by the apiary each was written under) and Net YTD, which
  shows only where the viewer may open the apiary's financial report. The dashboard and the page share one inspections
  query.
- **Free text is a note block (tasks 0265, 0266).** Inspection External check (now directly after the header strip, as
  it happens before the hive is opened), Action taken and Notes, the queen and queen observation Notes, and the calendar
  action Description appear as a heading with the text full width, line breaks and bullets kept, instead of a one-row
  table. `.hivelog-prose` is a stable class for themes.
- **Queen Origin is a tile (task 0267)**; the queen page no longer has a Details table.
- **The apiary page no longer lists members (task 0268).** The list is behind Manage members, beside Edit. The page's
  cache now always carries the membership list tag, so the Your role tile follows a role change.
