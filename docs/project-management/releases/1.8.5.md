# Release 1.8.5

## Highlights
- **Dashboard "Needs attention" — Done / Ignored parity (task 0071).**
  The `/hivelog` dashboard seasonal rows offered only a single "Report
  done" button, and its label — `t('Report done')`, lower case — had no
  `.po` entry, so it rendered in English even where `/hivelog/apiary/1`
  showed the translated label. Seasonal rows now render a
  `hivelog:button-group` with **Done** + **Ignored**, matching the
  apiary and hive calendar checklists, so a seasonal task can be
  dismissed as not-applicable straight from the dashboard.
- **Shorter report-button labels.** The apiary and hive calendar
  checklist buttons are relabelled `Report Done` / `Report Ignored` →
  **`Done`** / **`Ignored`** — they no longer wrap in the narrow
  Operations column on phones, and the dashboard now resolves the same
  `Done` / `Ignored` translations (`Udført` / `Ignoreret`, already in
  `hivelog.da.po` from the status-filter labels).

## Upgrade notes
- No API or schema change. Behaviour change is limited to the dashboard
  gaining an "Ignored" action on seasonal rows and the three report
  buttons being relabelled to their short forms. No CSS change — the row
  reuses `.hivelog-attention__action` + `.hivelog-button-group`.
