# Release 3.2.1

Patch release for 3.2.0. No schema change, no update hook.

## Changes
- **The error-page component is hidden from Canvas.** On a site running the Canvas page builder, 3.2.0's
  `hivelog:error-page` component was registered automatically (`canvas.component.sdc.hivelog.error-page`), so the error
  scene appeared in Canvas's component library and the site's configuration drifted from its sync directory. The
  component now carries `noUi: true`, the standard way to opt an SDC out of page builders; the 404 and 403 pages work
  exactly as before.

## Upgrade notes
Run `drush cr`. **A site that already ran 3.2.0 under Canvas keeps the generated config**: delete
`canvas.component.sdc.hivelog.error-page` (`drush config:delete canvas.component.sdc.hivelog.error-page`) and run
`drush config:status`; if a `canvas.folder.*` shows as different, it is the folder that component was filed in, so export
or revert it with the rest of your configuration. A site without Canvas needs nothing.
