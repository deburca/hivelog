# Release 1.8.2

## Highlights
- **Hive page: "Previous Queens" block removed.** The hive canonical
  page (`/hivelog/hive/{hive}`) listed every retired queen in a table
  below the current-queen section. That history is already one click
  away via "View all Queens" (and each retired queen's own page), so
  the block was redundant. `HiveController::buildQueenSection()` no
  longer appends it and `buildQueenHistorySection()` is gone; the
  "View all Queens" link stays. `Hive::getQueens()` is unchanged and
  still drives the observation aggregation and the observation filter's
  queen options. Dead `.hivelog-queen-history` CSS removed.
